_____________JSP____________
jsp is an alternative technology for servlets 

Phases in jsp:
|->translation phase - it converts .jsp into .java program internally, once this phase is completed the entire jsp program is available into java code
|->compilation phase - it converts .java into .class file provided no errors found in .java file 
|->Execution or running phase - it is the process of executing .class file by the container

Limitations of servlets v/s Jsp provides
* In order to develop any servlet java language must be known || * to write any jsp program java language is not necessary i.e., a non-java program can write a jsp page effectively.
* servlets does not provide any custom tag development || * jsp provides the fetures to develop custom tags
* servlets does not provide any implicit objects || *every jsp page contains n number of implicit objects such as out,session,exception,etc

Features of hibernate:
* Database independent-to generate db specific queries,allowing same java code on different rdbms
* Caching mechanism- it improves performance via a mandatory 1st level cache (session level),and an optional 2nd level cache(factory level) to reduce db hits
* lazy loading - optimizing where child objects only loaded when explicitly needed rather than during initial parent object fetch
* JPA Implementation - hibernate is a certified implementation of Jakarta persistence api

JDBC v/s Hibernate:
-> Code Type: procedural and heavy boiler plate code | oop and reduces boiler plate code
-> language type : native SQL | HQL
-> Exceptions : mandatory checked exception | unchecked exceptions
-> Mapping : manual mapping of result using joins | automatic ORM mappings using 1to1,1-to-many

SPRING Concepts

Spring framework is a robust platform which provides more security to an application .It is a popular opensource java platform that provides comprehensive infrastructure support for building a robust enterprise application.
it basically considered as a "framework of frameworks" .
key features of spring are:spring framework is highly modular,consisting of about 20 different modules   
* Inversion of control container:It manges the bean lifecycle and configuration of java objects. Eg: BeanFactory it is a interface and ApplicationContext
*Dependency injection :a concrete info of IoC,DI allows objects to receive their dependencies from spring container rather than creating them themselves . Eg:Setter injection and constructor injection
* Aspect-Oriented Programming(AOP) : it allows developers to modularize cross-cutting concerns like logging,security and transaction separating from the main business logic.
* Data access framework : spring provides an abstraction layer that simplifies database interaction. Eg: JDBC,JPA,Hibernate
* Spring MVC and WebFlux : mvc is synchronous and webflux is asynchronous
* Transaction Management: it offers a consistent abstraction for mapping transactions across different data access technologies
* testing support :
